# Project Rules for Last-Mile Delivery Tracker

## Code Explanation Preference
Whenever writing or modifying code, ALWAYS provide a comprehensive, clear, and beginner-friendly explanation detailing:
1. **What the code does**: Step-by-step breakdown of key functions, parameters, and algorithms.
2. **How it fits into the system**: Context within the overall backend/frontend architecture.
3. **Key Concepts to Know**: Technical definitions (e.g., PostGIS functions, JWT authentication, Finite State Machines) so the user gains a deep understanding of the implementation.
